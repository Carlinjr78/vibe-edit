# Código de conduta

Este projeto segue o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/). Em resumo:

- Trate todo mundo com respeito, seja qual for o nível de experiência, a origem ou a identidade da pessoa.
- Critique o código e as ideias, nunca a pessoa.
- Nada de assédio, ofensa, conteúdo sexual, ataque pessoal ou divulgação de dados de alguém sem permissão.
- Aceite as decisões do mantenedor sobre o que entra no projeto; discordar com educação é bem-vindo.

Vale nas issues, nos PRs, nas discussões e em qualquer espaço do projeto.

## Como denunciar

Mande uma mensagem privada ao mantenedor pelo perfil do GitHub ([@Carlinjr78](https://github.com/Carlinjr78)). Toda denúncia é tratada com sigilo. Quem descumprir as regras pode receber um aviso, ser bloqueado temporariamente ou banido do projeto.
