# Referências

Sua biblioteca de cortes. Use a mesma organização de `estilos/`, por exemplo `referencias/video-curto/games/nome-do-video/`. Cada referência é uma pasta com um `nota.md`:

```markdown
# Nome ou link do vídeo

**Arquivo:** <pasta de mídia>/_referencias/nome-do-video.mp4
**O que eu gosto:** o gancho dos 3 primeiros segundos e o ritmo dos cortes.
**Copiar:** legenda entrando de baixo; zoom rápido na palavra forte (aos 0:12).
**Som:** whoosh grave nas trocas, música quase some quando ele fala.
**Evitar:** muito texto na tela no final.
```

Se o vídeo não estiver na internet, guarde o arquivo em `_referencias/` dentro da pasta de mídia (`VIDEO_MIDIA`), fora do repositório. Só a nota fica aqui.

O Claude consegue ver os quadros do vídeo, mas não ouvir. Por isso, descreva sempre o que importa no som.
