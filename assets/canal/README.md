# Imagens do seu canal

Coloque aqui o avatar usado nos modais de inscrição, curtida e Twitch. Esta pasta fica fora do Git (só este README vai para o repositório).

- Quadrado, 400×400, com o rosto ou o logo no centro (o modal corta em círculo).
- O nome do arquivo é o `avatar` do perfil em `src/canal.json` (padrão: `avatar.jpg`).
- Sem avatar, o modal mostra a primeira letra do nome do canal.

Mais de um canal? Crie outro perfil em `src/canal.json`, com outro avatar, e escolha em cada vídeo com `"perfil"` no `projeto.json`.
