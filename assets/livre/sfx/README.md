# Efeitos sonoros

`pop.wav`, `whoosh.wav` e `stamp.wav` são sintetizados por `scripts/sfx_sinteticos.py`: originais, podem ir em qualquer vídeo.

Para trocar por outro som, coloque um `.wav` com o mesmo nome aqui. Para voltar aos originais:

```bash
.venv/Scripts/python.exe scripts/sfx_sinteticos.py
```
