# Músicas

Coloque aqui faixas com licença livre, como as da Biblioteca de Áudio do YouTube. Música com direitos autorais pode bloquear o vídeo no YouTube, no TikTok e no Instagram.

Os arquivos ficam fora do Git. Para usar uma faixa:

```bash
.venv/Scripts/python.exe scripts/mixar_musica.py videos/<projeto> assets/livre/musicas/faixa.mp3
```

Sem faixa, o `mixar_musica.py` compõe uma trilha chiptune original (`scripts/musica_chiptune.py`), sem risco de direitos autorais.
